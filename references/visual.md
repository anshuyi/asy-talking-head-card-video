# 3:4真人卡片样式

固定输出1080×1440、30fps。背景浅蓝到暖白、浅紫，白卡x60/y50/w960/h1350；图解区x108/y190/w864/h710；人物圆窗中心(300,1110)、直径360；底部字幕中线1344，最长两行；进度线y1380。

颜色：正文#203e69，重点#265fd0，辅助#6f8099。字体用本机实际存在的中文字体文件，路径在运行配置中提供；不把字体或私人素材偷偷打进分发包。模板以等比尺寸绘字，超宽直接报错，要求重新断行或简化图解。

真人裁切由新输入决定：crop{x,y,size}为源视频正方形取景，不是最终窗口大小。默认中心框只是起点，必须preview核对头顶、脸、下巴、肩部和动作极值；不能因任务开始就自动标已检查。原片位置漂移或硬切导致单框无法容纳时，按真实镜头分段建立工作源或调整窗口方案，不能逐帧追脸抖动。

有烧录字时优先避开，字幕或贴纸压到人物时，不承诺可自动去除。默认不做补画抹字。圆窗等比缩放加遮罩，音轨与人物时间从0一致，不挪动口型。保留原素材清晰度的限制，1080输出不等于源人物变高清。

渐显/上提约0.3秒；文字稳定阅读时间按本条发音决定。不复制截图里的播放器、点赞栏或博主标识。
