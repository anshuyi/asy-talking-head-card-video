# 从声音建立内容

1. 音轨是转写的必要输入；画面字幕、口播稿都不是必要输入。使用本机离线faster-whisper，word_timestamps=true，保留识别诊断。ASR进程使用配置目录的跨进程锁，其他任务正在转写时等待或稍后继续。
2. 检查首句、末句、人名、工具名、数字、否定词和低置信词。原字幕也可能错，不把OCR当成真值。疑点回听或缩短区间复识别；重要疑点仍无法确定时问用户，未解决则仅候选片并标注。
3. 字幕按语义与停顿切为1—2行，起止取自真实词/句时间，不按字数平均分配。转写后的重复、语气词不能擅自删去音频；字幕修正需保留修改前文本与理由。
4. timeline中 `transcript_review` 必须记录status、method、unresolved；reviewed只能用于实际核对，不能为了通过验证改标记。caption的source_span必须指向原音轨区间，非逐字概括只能用于图解，不能冒充字幕。
5. 不清晰音轨、静音或多人重叠属于明确限制。没有可靠转写就停止内容编排，不凭图像猜台词。
6. 字幕与上方逐字引用重复时，在对应caption设置 `display:false` 并说明 `hidden_reason`，原字幕文字及时间仍保留，避免漏登记。图解摘要不是原话，须保持含义而不增加承诺或事实。
