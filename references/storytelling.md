# 稳定风格与可变内容

先提炼每段让观众理解的关系，再选最少的组件。不要每隔固定秒数切画面，不强制九段，不照抄某条演示片的标题。

| 内容 | mode | 编排 |
|---|---|---|
| 步骤、顺序 | flow | 2—4步，讲到才出现，可保留前项 |
| 因果、条件 | causal | 有向关系，先原因后结果，不编因果 |
| 两种情况 | compare | 两列对照，标签和简短解释 |
| 并列要点 | cards | 1—3张卡片，逐项显现 |
| 提示词、引用 | quote | 原话1—2行，必要时关闭同句底字幕 |
| 开头、过渡、结论 | statement | 一条主张加简短辅助内容，保持留白 |

每个scene登记purpose（观众需要理解什么）、source_span（口播依据）、title（最多两行）、items（标签/说明/出现时刻）、note和side。items的at必须在本段范围内并来自对应话语落点；转场先退上一组再引入下一组。画面根据render(t)独立生成，反向寻帧不能复活旧文字。

正文长时分段，不靠小字塞屏幕。人物一直是原视频，不跟随内容切换成卡通。真实数据、证据和图片只有用户提供或明确授权且核实来源时才加入。
