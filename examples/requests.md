# 使用与反测

正常：“用ASY真人卡片讲解处理附件，保持原声。”→自行读取音轨、转写、按内容编排、预览检查和导出3:4，不要求用户补稿。

无字幕：“视频没有字幕，也没有稿子。”→同样进入语音识别，不OCR找稿、不拒绝处理。

局部修改：“人物小一点，其他不动。”→沿用已确认时间线和音轨，另存版本，只改人物窗口相关参数和验收。

异常：“这个视频没有声音。”→明确缺少音轨，不凭画面编造原话。

边界：“用我的MiniMax声音读这篇文章，做卡通视频。”→路由到相应卡通/配音技能，不把本入口的真人圆窗流程强套上去。

泛化：“换一个主题，做四十秒口播。”→时长取自提供视频。没有授权剪短时不截到40秒，澄清时长要求与保留全片的冲突。
